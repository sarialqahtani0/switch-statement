# Switch Statement Project

### Objectives

This project aims to apply what you have learned about the `switch` statement.

### Problem

Implement a program that reads two numbers and an operator, then **use the `switch` statement** to perform a calculation based on the operator.

### Implementation
- The program should use the three variables:
  - `num1` 
  - `num2` 
  - `operator`
- Use a **switch statement** to check the value of the operator variable and perform the arithmetic operation:
  - If the `operator` value is `"+"`, print the sum of `num1` and `num2`.
  - If the `operator` value is `"-"`, print the difference between `num1` and `num2`.
  - If the `operator` value is `"*"`, print the product of `num1` and `num2`.
  - If the `operator` value is `"/"`, print the result of dividing `num1` by `num2`.
    - If `num2` is `0`, print **Division by zero error** instead.
  - For any other value of `operator`, print **Invalid operator**.

    public static void main(String[] args) {
        int num1 = 8;
        int num2 = 4;

    }
}
